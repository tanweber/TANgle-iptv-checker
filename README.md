# TANgle - IPTV Checker

[English version](README_EN.md)

Веб-интерфейс для умного управления IPTV-плейлистами.
TANgle автоматически собирает единый M3U-плейлист из нескольких источников, проверяет каналы на доступность и скорость отклика, удаляет дубли и формирует ТВ-программу (EPG) на неделю вперёд только для каналов, попавших в плейлист.

Этот проект был разработан с использованием MiMo Code — AI-помощника для программистов от Xiaomi.

## Возможности

- **Проверка IPTV-каналов** — параллельное тестирование доступности каналов из M3U и M3U8-плейлистов с измерением времени отклика.
- **Формирование единого плейлиста** — объединение нескольких плейлистов в один с правилами отбора по скорости (быстрые / средние / медленные) и минимальной доступности.
- **Управление каналами** — включение/отключение отдельных каналов, редактирование групп. Каналы, которые не проходят правила плейлиста (недоступные, не проверенные, слишком медленные, с низкой доступностью), отключаются автоматически, а подсказка объясняет причину.
- **Автоматическое удаление дублей** — из повторяющихся каналов в плейлист попадает самый быстрый.
- **ТВ-программа (EPG)** — скачивание и объединение XMLTV из нескольких источников. Для каждого канала программа берётся из одного источника с наибольшим покрытием, id каналов совпадают с `tvg-id` плейлиста, файл проверяется на корректность XML. Есть сжатая версия `/epg.xml.gz`.
- **Пользователи и персональные ссылки** — у каждого пользователя свои ссылки на плейлист и ТВ-программу. Их можно скопировать в один клик, временно отключить или удалить; видно время последнего подключения, IP-адрес и устройство.
- **Безопасность** — весь API доступен только после входа, пароль хранится в виде хеша (PBKDF2), смена логина и пароля прямо в интерфейсе.
- **Чистый адаптивный интерфейс** — удобен на ПК, планшетах и смартфонах.
- **7 тем оформления** — Авто, Тёплая, Тёплая тёмная, Светлая, Тёмная, Nord, Лес.
- **Мультиязычность** — переключение EN/RU в реальном времени.
- **Автоматизация** — встроенный планировщик проверки каналов и обновления EPG.
- **Простота развертывания** — Docker, все настройки в одном файле `.env`.

## Установка

Нужны Docker и Docker Compose.

```bash
git clone https://github.com/tanweber/TANgle-iptv-checker.git
cd TANgle-iptv-checker
cp .env.example .env      # затем отредактируйте .env
docker compose up -d --build
```

Откройте в браузере `http://<адрес-сервера>:9239` и войдите с логином и паролем из `.env` (по умолчанию `admin` / `admin`). **Сразу смените пароль**: Настройки → Вход в систему.

Дальше:
1. **Источники** → добавьте M3U-плейлисты (источники EPG уже добавлены по умолчанию).
2. **Каналы** → «Проверить сейчас». Первая проверка и сборка ТВ-программы занимают несколько минут.
3. **Настройки** → выберите правила формирования плейлиста.
4. **Пользователи** → «Добавить пользователя», введите любое имя и скопируйте ссылку на плейлист. Вставьте её в плеер — ТВ-программа подхватится автоматически из заголовка плейлиста (или укажите её вручную кнопкой «Программа»).

### Обновление

```bash
git pull
docker compose up -d --build
```

База (`data/`), плейлист и EPG (`playlist/`) хранятся на хосте и при обновлении сохраняются.

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TANGLE_PORT` | `9239` | Порт веб-интерфейса на хосте |
| `PUBLIC_URL` | `http://localhost:9239` | Публичный адрес сервиса без `/` в конце. Из него строятся ссылки пользователей, поэтому он должен быть доступен плеерам (например, `https://iptv.example.com`) |
| `EPG_DAYS` | `7` | На сколько дней вперёд формировать ТВ-программу |
| `ADMIN_LOGIN` | `admin` | Логин администратора — только при первом запуске |
| `ADMIN_PASSWORD` | `admin` | Пароль администратора — только при первом запуске |

`ADMIN_LOGIN` и `ADMIN_PASSWORD` применяются только к новой (пустой) базе. Потом логин и пароль меняются в интерфейсе.

Остальные настройки (интервалы проверки и обновления EPG, таймауты, число потоков, правила плейлиста) задаются в интерфейсе на вкладке «Настройки».

### Обратный прокси

Для доступа по HTTPS поставьте перед TANgle обратный прокси (nginx, Caddy, Traefik) и укажите внешний адрес в `PUBLIC_URL`. Пример для nginx — в `nginx.conf`. Прокси должен передавать заголовок `X-Real-IP`, чтобы в списке пользователей были видны реальные IP. Сжатие (gzip) на прокси лучше отключить: некоторые плееры (Televizo) не умеют его читать.

## API

Персональные ссылки пользователей (без входа, `{token}` — уникальный код пользователя):

| Метод | Путь | Описание |
|-------|------|----------|
| GET, HEAD | `/u/{token}/playlist.m3u` | Плейлист |
| GET, HEAD | `/u/{token}/epg.xml` | ТВ-программа (XMLTV) |
| GET, HEAD | `/u/{token}/epg.xml.gz` | ТВ-программа в gzip |

Отключённая, удалённая или неизвестная ссылка отвечает 404.

Требуют входа (cookie сессии):

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/login` | Вход |
| POST | `/api/auth/password` | Смена логина и пароля |
| GET | `/api/stats` | Статистика каналов |
| GET | `/api/channels` | Список каналов (с причиной исключения из плейлиста) |
| PUT | `/api/channels/{id}/toggle` | Вкл/выкл канал |
| PUT | `/api/channels/{id}/group` | Изменить группу |
| GET, PUT | `/api/settings` | Настройки |
| GET | `/api/sources` | Источники плейлистов |
| GET | `/api/epg-sources` | Источники EPG |
| POST | `/api/check` | Запустить проверку |
| GET, POST | `/api/users` | Пользователи и их ссылки / добавить пользователя |
| PUT, DELETE | `/api/users/{id}` | Переименовать, отключить / удалить пользователя |

## Что нового в v2.2

- **Персональные ссылки вместо общих.** Вкладка «Пользователи»: для каждого пользователя создаются свои ссылки на плейлист и ТВ-программу со случайным кодом. Ссылки можно скопировать, временно отключить или удалить — отключённая ссылка перестаёт работать сразу.
- Для каждого пользователя видно время и дату последнего подключения, IP-адрес и устройство.
- Общие ссылки `/rus_fixed.m3u` и `/epg.xml` отключены. **При обновлении с v2.1** создайте пользователей и замените ссылки в плеерах.
- Вкладка «Подключения» со статистикой удалена.
- Из ТВ-программы отбрасываются ошибочные передачи, у которых окончание раньше начала.

## Что нового в v2.1

- **Исправлена ТВ-программа**, на которой плееры выдавали ошибку:
  - в заголовке плейлиста `url-tvg` указывал на сам плейлист, а не на EPG;
  - передачи ссылались на каналы, которых нет в файле;
  - программы разных источников и региональных копий каналов («+2», «+4») смешивались и перекрывались;
  - id каналов в EPG не совпадали с `tvg-id` плейлиста, и у большинства каналов программа не отображалась.
- ТВ-программа формируется на **7 дней** (настраивается через `EPG_DAYS`). Сборка идёт потоково и требует в разы меньше памяти.
- Новая сжатая версия `/epg.xml.gz`. На `/epg.xml` плееры, которые не умеют gzip (Televizo, okhttp), получают несжатый файл — в том числе за обратным прокси (nginx, Nginx Proxy Manager), который раньше сжимал ответ сам и ломал обновление программы в Televizo.
- Плейлист и EPG отдаются с `Last-Modified` и `Content-Length` и поддерживают `HEAD`, чтобы плееры могли проверять обновления.
- **Безопасность:** весь API закрыт авторизацией (раньше настройки, включая пароль, были доступны без входа), пароль хранится в виде хеша, смена пароля с проверкой текущего.
- **Новый дизайн** в чистом стиле, 7 тем (Авто, Тёплая, Тёплая тёмная, Светлая, Тёмная, Nord, Лес), переработанная страница входа, копирование адресов плейлиста и EPG в один клик.
- **Автоотключение каналов**, которые не проходят правила плейлиста, с подсказкой о причине. Правила скорости стали строгими: каждый флажок отвечает только за свой диапазон.
- Все личные настройки вынесены в `.env` (шаблон — `.env.example`).
- Исправлено: сортировка по доступности, счётчики каналов после перезапуска, расписание обновления EPG, спецсимволы в названиях групп, зависимости в Docker-образе теперь зафиксированы по `requirements.txt`.
